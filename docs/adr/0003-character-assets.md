# 0003 — 角色素材来源与授权

**Status:** accepted
**Date:** 2026-11-06
**Decision owner:** 用户
**Blocks:** 是否可以把立绘放进仓库、原型能否对外演示

## 背景

用户指定角色形象为社区鲸鱼娘，给出的链接是
[`TreapGoGo/deepseek-whale-girl`](https://treapgogo.github.io/deepseek-whale-girl/)。
渲染路线已在 [ADR 0002](0002-character-rendering.md) 修订为 2.5D 立绘方案，
现在要把"用哪套图"和"能不能用"定下来。

## 事实核查

| 来源 | 内容 | 许可状态（2026-11-06 核实） |
| --- | --- | --- |
| `TreapGoGo/deepseek-whale-girl` | 参考图、提示词、社区画廊；两套三视图设定图 | 仓库代码 **MIT**；README 明确写明**角色设定图、社区投稿与外部素材不在该许可内**，"使用前请先核实对应许可"。**不能当作授权来源** |
| `Sutera-Diffusus/dsh-whale-musume` | 92 张 512×512 透明立绘，语义命名 | 仓库声明 **MIT**，README 的 License 段只有一行 MIT，未单独声明美术例外；但立绘由"第三方图像接口"批量生成（`tools/gen-assets.py`），且角色形象的上游另有出处 |
| `schrieeeffer/shenshen-codex-pet` | 精灵表数据库（192×208 帧） | 有独立的 `ASSET_LICENSE.md`：**CC BY-NC-SA 4.0**，并记录上游为"上善无形"的鲸鱼娘形象，同样 CC BY-NC-SA 4.0 |

两个必须说清的风险：

1. **MIT 覆盖的是代码，不是角色。** 一个仓库把美术放在 MIT 下，只说明该仓库的维护者
   这样声明；如果形象本身源自他人在先的作品，维护者无权用 MIT 覆盖它。
   shenshen 的 `ASSET_LICENSE.md` 恰好记录了这条上游链（上善无形 → CC BY-NC-SA 4.0），
   所以"musume 的立绘可以随意商用"这个结论不成立。
2. **鲸鱼娘是非官方社区形象。** 资产库自己写明"不代表深度求索公司或其官方立场"，
   且页面标注"如涉及侵权，请联系删除"。把角色与 DeepSeek 品牌一起用于商业用途，
   除了角色设计权，还叠加商标风险。

## 选项

| 方案 | 权利状态 | 代价 | 适用 |
| --- | --- | --- | --- |
| A. 用 musume 的出图（非商业） | 需署名、非商业、互惠共享；上游权利未完全厘清 | 零成本，立即可用 | **原型/内部演示** |
| B. 委托原创同风格角色 | 干净，权利自有 | 数千元 + 1~2 周 | 上线产品 |
| C. 用社区 ComfyUI 工作流自行生成 | 取决于基座模型与 LoRA 条款，需要逐项核对 | 时间成本，需本地算力或付费接口 | 想要"像"但不要别人的图 |
| D. 取得原作者书面授权 | 取决于对方意愿 | 不可控 | 有明确商业计划时 |

## 建议

**原型阶段用 A，并在仓库里把边界写死：**

- 立绘归档在 `apps/web/public/character/`，同目录放 `ATTRIBUTION.md`，写明作者、
  来源链接、许可、修改说明；
- 页面页脚保留"非官方、非商业演示，素材遵循 CC BY-NC-SA 4.0"的说明；
- 不使用 DeepSeek 商标做产品名、域名或图标，避免暗示官方背书；
- **在上线或收费之前，必须切到 B 或 C**，届时只替换 `public/character/` 与
  一份清单文件，代码不动。

理由：原型的目的是验证"情绪互动是否成立"，不是解决角色版权。用一套现成立绘把
观感做出来，比先花两周等原创美术更符合这一阶段的收益；而把授权边界写在仓库里，
可以避免"先用了再说"的惯性。

如果用户的目标本来就是商用产品，则应该直接走 B，A 只作为临时占位。

## 决策

**采用方案 A：素材维持 CC BY-NC-SA 4.0，作为非商业演示的原型素材。**
用户于 2026-11-06 确认。

落地时必须同时满足四条义务，缺一条就不合规：

1. **署名（TASL）**：`T` 作品名、`A` 作者、`S` 来源链接、`L` 许可链接，
   加上"是否修改"的说明，写进 `apps/web/public/character/ATTRIBUTION.md`。
2. **许可随图走**：同目录放 CC BY-NC-SA 4.0 全文 `LICENSE`；任何改编
   （裁剪、放大、调色、切片）仍以此许可发布。
3. **非商业**：站点不得收费、不得挂广告、不得作为付费服务的入口。
   Cloudflare Workers 免费额度部署符合这一条。
4. **界面可见**：页脚常驻一行"非官方、非商业演示，角色素材遵循
   CC BY-NC-SA 4.0"，链接到来源与许可。

代码与素材的许可**分开声明**：根 `LICENSE` 只覆盖代码，素材许可只在
`apps/web/public/character/` 内生效，并在根 `NOTICE.md` 说明这条边界。
不得把立绘打进任何对外发布的 npm 包。

范围说明：ShareAlike 作用于**改编后的美术作品**，不要求展示它的代码同样以
CC BY-NC-SA 发布；但把立绘与其它素材合成进同一张图，会让合成结果整体受
BY-NC-SA 约束，因此角色层保持独立，不与环境特效烘焙到同一位图。

## 后果

- **选 A**：三天可交付，观感直接到位；技术债是"素材非自有"，上线前必须替换，
  替换工作量约半天（换图 + 校准锚点），不动代码。
- **选 B**：等待期 1~2 周，期间可以用 A 占位推进；上线无权利瑕疵。
- **选 C**：需要对基座模型与每个 LoRA 的许可逐项核对，产出风格一致性不如 A 稳定。
