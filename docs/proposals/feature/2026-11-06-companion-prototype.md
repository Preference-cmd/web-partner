# 伴侣小生命：情绪互动与状态调试原型

**Class:** feature
**Status:** proposed
**Date:** 2026-11-06
**Source:** [`docs/research/2026-11-06-companion-prototype.md`](../../research/2026-11-06-companion-prototype.md)

## Goal

交付一个可部署到 Cloudflare Workers 的单页原型：一个会呼吸的伴侣角色，能随用户的
话语与快捷互动切换四种情绪，背景光影与之同步；右侧调试台显示状态与日志，并能手动
强制切换。原型用来回答三个问题：

1. 情绪切换在**观感上**是否成立——用户不看代码，只看角色与环境，能不能读出"它现在
   开心/害羞/困了"。
2. 环境光影与角色状态联动，是否比固定背景更能撑起"陪伴感"。
3. 调试面板作为一个可对外演示的窗口，是否够专业、够好用。

原型不追求产品化，但追求"看起来不像实习生作业"。

## 范围

**做：**

- 主视图：社区鲸鱼娘立绘常驻（2.5D），同一角色、同一画布的四张姿态——`idle-cute`、
  `celebrate`、`blush`、`sleep`——对应待机 / 开心 / 害羞 / 犯困。切换时贴图交叉淡化，
  全程叠加顶点位移做呼吸与轻摆。
- 互动：底部一个输入框 + 三个快捷按钮（摸摸头 / 夸夸它 / 哄它睡觉），回车与点击
  均可触发；角色以气泡回应。
- 环境：背景径向渐变、漂浮粒子、暗角随情绪平滑过渡（≥600 ms）；three 侧灯光
  与 DOM 侧主题色订阅同一份状态。
- 调试面板：状态码、内部 mood 值、当前动画与进度、最近 50 条互动日志、强制切换、
  灯光主题、系统气泡、FPS 与渲染器信息。
- 情绪判断：本地启发式分类器为默认；`/api/classify` 为可选叠加，失败静默回落。
- 部署：`wrangler deploy` 一次上线；静态资源与 `/api/*` 同在一个 Worker。

**不做（本期明确排除）：**

- 账号、登录、多角色、多会话。
- 数据持久化（不上 D1/KV，日志只在内存里，刷新即清空）。
- 语音输入输出、TTS、口型同步。
- LLM 生成对话文案——本期只做**情绪分类**，文案走本地模板池。
- 移动端原生壳、PWA 离线安装、多语言。
- 付费 API 与任何需要前台付费流程的服务。

## Accept

勾选前需附证据（截图、录屏、命令输出或线上 URL）。

- [ ] 冷启动到角色可交互 < 2.5 s（本地生产构建，宽带）。
- [ ] 待机状态有可见的呼吸与轻摆（顶点位移），静置 30 s 不出现僵硬或穿帮。
- [ ] 三个快捷按钮分别稳定进入开心 / 害羞 / 犯困，立绘在 350 ms 内完成交叉淡化，
      背景与灯光在 800 ms 内同步变化。
- [ ] 输入「今天好累，想睡觉」进入犯困；「你最棒了」进入开心；「你走开」进入害羞。
- [ ] 同一情绪下连续两次触发不会导致立绘反复闪切（最短停留 2 s 生效）。
- [ ] 立绘与背景之间没有"贴纸感"：角色有落地投影或光晕，边缘无锯齿与白边。
- [ ] 调试面板显示当前渲染器与能力标志；切换渲染器后角色正常挂载、情绪状态不丢。
- [ ] 调试面板能看到状态码、mood 值与最近 50 条日志，且来源（用户/快捷/调试/系统/云端）可区分。
- [ ] 面板内可强制切换四种情绪、切换四种灯光主题、发送系统气泡，三项互相独立。
- [ ] DevTools 设为 offline 后，除云端分类外全部功能仍可用，且日志记录回落事件。
- [ ] WebGL 不可用时显示降级画面与说明，不白屏、不抛未捕获异常。
- [ ] 尊重 `prefers-reduced-motion`：粒子与呼吸降级为静态。
- [ ] `pnpm check` 全绿；`wrangler deploy` 成功，线上地址可访问。

## Phases

| 阶段 | 交付 | 退出条件 |
| --- | --- | --- |
| M1 骨架 | 脚手架、渲染槽位端口 + Canvas 2D 适配器、立绘加载、呼吸位移、背景 | 角色在页面上动起来，无控制台报错 |
| M2 情绪 | 情绪 reducer + 四状态映射 + 背景联动 + 输入与快捷按钮 + 气泡 | 四条 Accept 中的交互项通过 |
| M3 调试台 | 日志、强制切换、灯光主题、系统气泡、运行信息 | 面板三项互不干扰，日志可读 |
| M4 打磨 | PixiJS 适配器（网格变形 + 滤镜光晕）、粒子、移动端适配、降级与可访问性 | 全部 Accept 勾选，可部署演示 |

工作量估算见调研 §8：合计约 3 天。

## Risks

| 风险 | 对策 |
| --- | --- |
| 立绘切换像"幻灯片翻页" | 淡化时间压到 350 ms，叠加闪白与粒子爆发遮住姿态瞬变；同一情绪不重播 |
| 静态图没有四肢动作，显得像视觉小说 | 用呼吸变形、粒子、气泡与光影承担"活"的部分；接受这一取舍（ADR 0002 修订） |
| 素材非自有，上线前必须替换 | 授权边界与署名写进 `ATTRIBUTION.md`，替换只动图片与锚点，不动代码（ADR 0003） |
| 移动端掉帧 | DPR 夹到 `[1, 1.5]`，窄屏关 Bloom，粒子数按面积缩放 |
| 状态抖动导致角色抽搐 | 最短停留 2 s + 置信度阈值 + reducer 单测 |
| 选型反复 | 渲染走 `CharacterController` 端口，换实现不动主流程（ADR 0002 §可逆性） |

## Open

1. **渲染路线**：3D（建议）、Live2D、Spine——见 ADR 0002。
2. **视觉基调**：深空冷色 + 情绪点缀色（建议），还是暖色治愈系。
3. **云端对比模式**是否进 M3：默认不进；它增加半天工作量，但能让面板更像"调试台"而非"遥控器"。
