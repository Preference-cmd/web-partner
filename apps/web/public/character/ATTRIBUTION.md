# 角色素材署名与许可

本目录的四张角色立绘用于「伴侣小生命」的非商业演示。

- **作品**：鲸鱼娘（dsh-whale-musume）
- **原始形象**：上善无形，[公开来源](https://www.bilibili.com/opus/1231977657712771073)
- **立绘与姿态生成**：Sutera-Diffusus，[dsh-whale-musume](https://github.com/Sutera-Diffusus/dsh-whale-musume)
- **许可**：[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)，全文见同目录 `LICENSE.txt`
- **来源文件**：上游 `assets/generated/` 中的 `dsh-whale-state-idle-cute.webp`、`dsh-whale-state-game-happy.webp`、`dsh-whale-state-blush.webp`、`dsh-whale-state-sleep.webp`
- **本仓库的修改**：选取这四张，重命名为 `idle/happy/shy/sleepy.webp`，未改动像素；运行时由 Canvas 2D 按呼吸切片与 350ms 交叉淡化呈现。

使用限制：非官方、非商业，不收费、不挂广告、不作付费入口；改编后的视觉素材仍以 CC BY-NC-SA 4.0 发布。
